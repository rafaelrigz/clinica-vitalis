# Clínica Vitalis — Landing Page

Landing page estática desenvolvida para a disciplina de Programação e Desenvolvimento Web (CEUB).

## Sobre o projeto

Página de apresentação institucional de uma clínica de saúde fictícia, contendo descrição dos serviços oferecidos, equipe médica e formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório: `git clone https://github.com/rafaelrigz/clinica-vitalis.git`
2. Abra a pasta no VS Code
3. Abra o arquivo `index.html` diretamente no navegador (duplo clique)
   - Ou, se preferir com live reload: instale a extensão Live Server no VS Code e clique em "Open with Live Server"
